# Telegram Bot Bridge 🌉

這個專案實現了一個「Telegram 任意門」，讓你可以透過 Telegram Bot 遠端無縫控制你的 AI Agent (Antigravity)。

## 🌿 分支架構說明

本專案目前有兩個主要分支，採用完全不同的底層控制技術：

### 1. `main` 分支（UI 模擬自動化）
*   **控制原理**：依賴 macOS 的 **AppleScript (`osascript`)** 強制將視窗喚醒至前景，並透過 `pyperclip` 模擬剪貼簿 `Cmd+V` 貼上操作。
*   **優點**：架構簡單，泛用性強。
*   **缺點**：容易被干擾，且必須確保輸入框處於焦點狀態。

### 2. `feature/cdp-integration` 分支（本分支：CDP 深度整合版）✨
*   **控制原理**：透過 **Chrome DevTools Protocol (CDP)** 直接與底層核心通訊，徹底脫離對視窗焦點與剪貼簿的依賴。
*   **核心優勢**：
    *   **無感背景執行**：即使視窗被遮擋或最小化，指令依然能精準送達，完全不影響你當前的工作。
    *   **DOM 狀態機攔截**：內建「智能監控」機制，能自動識別 UI 中的「生成中/取消」狀態。
    *   **長任務耐力**：特別針對複雜任務優化，最高支援 4 分鐘的背景等待，確保完整抓取最終回覆。
    *   **精準過濾**：自動識別並屏蔽 AI 的「思考中」日誌 (opacity-70)，只回傳純淨的最終解答。
    *   **多專案切換**：支援即時切換不同的專案視窗進行下令。

## 🌟 CDP 分支進階功能

*   **啟動自動連線**：啟動 `tgbot` 時，系統會自動檢查 Antigravity 狀態，若未啟動則執行冷啟動，並自動推播連線成功通知到手機。
*   **自動鎖定活躍視窗**：預設自動鎖定目前電腦上「最活躍/最後操作」的專案視窗 (`[0]` 號視窗)，實現零設定開箱即用。
*   **多視窗管理指令**：
    *   `/list`：列出所有目前開啟的專案視窗。
    *   `/switch <編號>`：手動切換要控制的目標視窗。

## 🚀 快速開始

### 1. 安裝依賴
```bash
pip install -r requirements.txt
```

### 2. 設定檔 (config.json)
確保目錄下有 `config.json`，並填入你的 `bot_token`。

### 3. 啟動方式
```bash
python3 bot.py
# 或使用 alias
tgbot
```

## ⚠️ 注意事項
*   **偵錯模式**：Antigravity 必須以 `--remote-debugging-port=7800` 模式啟動（本專案的自動啟動腳本已內建此參數）。
*   **超時處理**：對於非常龐大的分析任務，請耐心等候，系統會在 AI 徹底回答完畢（Cancel 按鈕消失）後才進行發送。
